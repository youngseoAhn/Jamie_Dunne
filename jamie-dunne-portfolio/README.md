# Jamie Lee Dunne — Pastry Chef Portfolio

A bilingual Korean/English portfolio website built from Jamie Lee Dunne's resume and original pastry work collection.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The project is ready to push to GitHub. Deploy it with a Next.js-compatible host connected to the repository.

## Content

- Korean/English language switch
- Pastry work gallery using Jamie's original images
- Professional profile, expertise, career timeline, education, languages, and contact information
- Responsive layouts for desktop and mobile
- Custom social sharing preview image
